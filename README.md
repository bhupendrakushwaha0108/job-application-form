# Job Application Form (Web)

A simple and responsive Job Application Form built using HTML and CSS.  
This project is created to practice frontend form design and layout.

## Live Demo
https://bhupendrakushwaha0108.github.io/job-application-form/

## Features
- Clean and user-friendly UI
- Responsive form layout
- Input fields for personal details
- Job role selection dropdown
- Resume upload option
- HTML5 form validation

## Tech Stack
- HTML5
- CSS3
